# 📖 About

Smart Shop App is an Android-based shopping application developed using **Java** and **Android Studio**.

The application provides a smooth shopping experience where users can browse products, view product details, manage their shopping cart, and enjoy a clean and responsive user interface.

---

# ✨ Features

- 🛍️ Browse products
- 📦 Product categories
- 🔍 View detailed product information
- 🛒 Add products to cart
- ❤️ Simple and attractive UI
- ⚡ Fast navigation
- 📱 Android Material Design
- 🔄 Responsive layouts
